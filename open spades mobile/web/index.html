Credits & Licenses


  

   
   
OpenSpades Mobile is an Android port of the OpenSpades web client. The original C++ gameplay core (player movement, collision, weapons, hitscan, grenades, voxel map and structural collapse) runs as WebAssembly. Multiplayer uses the original ENet protocol over the phone's own UDP network — no relay server is involved.

Privacy

   
The app has no accounts, ads or analytics. It contacts the Build and Shoot server list and the game servers you choose to join; those servers see your IP address and player name.
